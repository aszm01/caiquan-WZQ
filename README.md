# 彩泉五子棋

> 三手定彩，一泉同源。玄岩裂风，覆云归泉。

一款彩泉宗改良的双人联机「五子棋 × 猜拳」小游戏：落子之前先出招（玄岩劲 / 裂风铰 / 覆云掌三绝技），落在同一格时靠猜拳定胜负。

## ✨ 功能特性

- **双人对战**：创建房间，好友加入即开局，实时对战
- **猜拳机制**：每次落子前先选「玄岩劲 / 裂风铰 / 覆云掌」三绝技，同格对撞时由猜拳决定棋子归属
- **观战模式**：每局最多 2 名观战者实时围观
- **移动端手势出招**：长按交叉点弹出方向盘，滑动一步完成出招（左=玄岩劲 / 上=裂风铰 / 右=覆云掌 / 下=取消），无需先点按钮再落子
- **重新开局**：双方同意即可一键再来一局
- **自定义昵称**：进入房间前可设置，未设置则自动生成

## 🎯 玩法说明

1. 打开页面，输入用户名并确认
2. 创建房间，把房间号分享给朋友；或从房间列表直接加入
3. 轮到你时出招并落子：**电脑上**先点选「玄岩劲 / 裂风铰 / 覆云掌」三绝技再点击交叉点落子；**手机上**长按交叉点后滑动出招（左滑=玄岩劲 / 上滑=裂风铰 / 右滑=覆云掌 / 下滑=取消），松手即完成
4. 双方都提交后结算：

   | 情况 | 结果 |
   | --- | --- |
   | 落在不同位置 | 双方棋子各自落位 |
   | 落在同一位置 + 猜拳胜出 | 胜方棋子占位 |
   | 落在同一位置 + 出招相同 | 该格下回合禁用，双方重新出招 |

5. 先在 15×15 棋盘上连成五子的一方获胜

## 🛠 技术栈

- 前端：原生 HTML + Tailwind CSS（CDN）+ Font Awesome（CDN），单文件无构建
- 后端：Node.js + [ws](https://github.com/websockets/ws)（WebSocket 实时通信）

## 🚀 本地运行

需要 Node.js 18+。

```bash
npm install
node server.js
```

浏览器打开 <http://localhost:8080>，开两个窗口（或一个普通窗口 + 一个无痕窗口）即可自测联机。

## ☁️ 部署到服务器

仓库附带 [deploy.sh](deploy.sh)，在 Linux 服务器上执行即可完成部署（pm2 保活 + 开机自启）：

```bash
bash deploy.sh
```

部署后访问 `http://<服务器公网IP>:8080`，详细步骤见脚本内注释。
